# Landing page mockups

## Current direction: version 2

- [Desktop: three-column grid](landing-desktop-v2.png)
- [iPhone: compact ownership cards](landing-iphone-v2.png)
- [Version 2 prompts](prompts-v2.md)

Task ownership leads the page. Red identifies a human-owned investigation;
gold identifies a problem the Archon is handling. Night Watchman and Sage
appear alongside the execution roles. Cards retain only project, task, owner,
and a concise state. Evidence and runtime diagnostics belong in details.

This revision removes slogans, summary tiles, connection/sync chrome,
full-width attention cards, and improvement metadata. Desktop uses three
columns; mobile uses one. Improvements become quiet rows below the fleet.
These choices supersede the original mockup direction below, including the
design document's two-column layout for this visual exploration.

The visual-review skill informed composition and copy reduction. These are
static image concepts, not a completed browser visual audit: interaction
states, CSS geometry, contrast compliance, and responsive behavior remain
unverified.

the root page (`/` → `/#/status`), not an implemented or deployed application.
All tasks, counts, timestamps, and telemetry are illustrative. The desktop
shows selected agents rather than the entire fleet.
